# Library Hub

Act as a Senior UI/UX Designer and Full Stack Software Architect.

Design a modern, responsive Library Seat Management and Fee Management web application for a private library. "DeskManagers" 

The interface should be simple, clean, and easy to use.

Design Style:

- Modern SaaS dashboard

- Minimal UI

- Material Design 3

- Rounded cards

- Soft shadows

- Blue and White theme

- Fully responsive (Desktop, Tablet, Mobile)

- Light and Dark Mode

Technology Stack:

- React

- TypeScript

- Tailwind CSS

- Node.js

- Express.js

- PostgreSQL (or Supabase)

- JWT Authentication

## Dashboard

- Total Seats

- Available Seats

- Total Students

- Pending Fees

Charts:

- Monthly Fee Collection

- Seat Occupancy

Recent Activities:

- New Admissions

- Fee Payments

- Seat Changes

------------------------

## Student Management

Add Student

Fields:

- Full Name

- Mobile Number

- Email

- Address

- Aadhaar Number (Optional)

- Joining Date

- Seat Number

- Monthly Fee

- Security Deposit

- Status (Active/Inactive)

Student Profile should show:

- Personal Details

- Assigned Seat

- Payment History

- Remaining Due

- Attendance (optional)

------------------------

## Seat Management

Display seats in a visual grid.

Example:

Seat 1

Seat 2

Seat 3

Seat 4

Each seat should display:

- Seat Number

- Student Name

- Status

Colors:

Green = Available

Red = Occupied

Yellow = Reserved

Clicking a seat opens details.

Allow:

- Assign Seat

- Change Seat

- Release Seat

------------------------
